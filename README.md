# Sistema de Inspeção de Requisitos

Este repositório é destinado à **documentação do Sistema de Inspeção de Requisitos**, desenvolvido como projeto prático da disciplina de Engenharia de Requisitos.

O sistema tem como proposta apoiar a análise de artefatos de Engenharia de Requisitos por meio do uso de **Large Language Models (LLMs)**. A aplicação permitirá que usuários submetam artefatos para inspeção, buscando identificar possíveis problemas como **ambiguidades, inconsistências, lacunas e outras irregularidades**.

Ao longo do desenvolvimento do projeto, este repositório reunirá os principais documentos produzidos na disciplina, como especificações de requisitos, casos de uso, modelos, diagramas e demais artefatos relacionados à definição e evolução do sistema.
