# HU-ART-09 – Visualizar diagramas associados a um artefato

**Como** um usuário do sistema,
**Eu quero** visualizar os diagramas associados a um artefato,
**Para que** eu possa conferir as representações gráficas vinculadas antes ou depois da inspeção.

## Critérios de Aceitação

1. **Dado** que um artefato possui um ou mais diagramas associados, **quando** eu acesso os detalhes desse artefato, **então** o sistema deve exibir os diagramas vinculados.
2. **Dado** que um artefato não possui nenhum diagrama associado, **quando** eu acesso seus detalhes, **então** o sistema deve informar que não há diagramas associados.
