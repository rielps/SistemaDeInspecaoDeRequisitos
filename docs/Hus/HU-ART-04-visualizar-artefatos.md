# HU-ART-04 – Visualizar artefatos cadastrados

**Como** um usuário do sistema,
**Eu quero** visualizar os artefatos que cadastrei, com suas respectivas informações (prioridade e status),
**Para que** eu possa acompanhar e localizar meus artefatos facilmente.

## Critérios de Aceitação

1. **Dado** que possuo artefatos cadastrados, **quando** eu acesso a lista de artefatos, **então** o sistema deve exibir cada artefato com, no mínimo, título, prioridade e status.
2. **Dado** que estou visualizando a lista de artefatos, **quando** eu seleciono um artefato específico, **então** o sistema deve exibir seus dados completos.
3. **Dado** que não possuo nenhum artefato cadastrado, **quando** eu acesso a lista de artefatos, **então** o sistema deve exibir uma mensagem informando que não há artefatos cadastrados.
