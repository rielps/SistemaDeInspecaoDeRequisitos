# HU-ART-07 – Alterar prioridade de um artefato

**Como** um usuário do sistema,
**Eu quero** alterar a prioridade de um artefato cadastrado,
**Para que** eu possa organizar quais artefatos devem ser tratados ou inspecionados primeiro.

## Critérios de Aceitação

1. **Dado** que possuo um artefato cadastrado, **quando** eu seleciono uma nova prioridade dentre as opções disponíveis, **então** o sistema deve atualizar a prioridade do artefato e refletir a mudança na lista de artefatos.
2. **Dado** que altero a prioridade de um artefato, **quando** a operação é concluída, **então** os demais dados do artefato devem permanecer inalterados.
